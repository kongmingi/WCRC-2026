# T28 확인

## 바뀐 것
- PSD 앞뒤 + 비틀림 동시 맞춤(`PerformMoveRotateAlign`)에서, 허용 범위 밖인데 계산된 속도가 10보다 작으면 10으로 올려서 움직인다
- 허용 범위 안인 성분은 0
- 위치: Mission2B.ino `RotateAlignFront2()` (새 함수), `PerformMoveRotateAlign()` 에서 호출
- Mobilebase.cpp 는 안 바꿈 (기존 `RotateAlignWithFront2PSD` 는 그대로 있고 안 씀)
- 값 변경 없음

## 왜
- 오차 4 정도면 속도 6 → 10 이하라 바퀴가 서고, 허용 2 에도 안 들어가서 끝나지도 않음 → 1~3초 헛돌고 오차 남김

## 확인 방법
| 명령 | 정상 |
|---|---|
| `t5 3` → `t5 3 2` → `rot 304 -5` 3번 | 매번 FR 302~306, FR-FL -8~-2, 1초 안쪽으로 끝남 |
| `t5 1` | FR-FL -28~-22, 전보다 빨리 끝남 |
| 흔들림 | 목표 근처에서 앞뒤로 왔다갔다 계속하면 이상 → 알려주기 |
