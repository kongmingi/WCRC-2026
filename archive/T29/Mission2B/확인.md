# T29 확인

## 바뀐 것
- 이동(move, 열 이동, Zone 이동)이 시간 안에 도착 못 하면 바퀴를 그 자리에서 멈춤 (남은 목표 취소)
- 시리얼: `[MOVE] timeout, stopped. dir N mm D` / 명령 전송 실패면 `[MOVE] send fail dir N mm D`
- dir 번호: 1 전진, 2 후진, 3 좌진, 4 우진, 5 좌회전, 6 우회전
- 위치: Mobilebase.cpp `DriveDistanceSmoothWithInternalAcceleration()` 끝부분
- Tuning: 속도 MOBILEBASE_SPEED / MOVE / SIDE / SEARCH 140 (팀이 바꾼 값 반영), MOVE_ALIGN_SPEED 160 그대로

## 왜
- 시간 초과 때 바퀴 목표가 살아 있어서 다음 동작(PSD 맞춤, 팔)과 섞여 꼬임

## 확인 방법
| 명령 | 정상 |
|---|---|
| `move L 100` 하는 동안 손으로 로봇 막기 | 삐 소리 + `[MOVE] timeout, stopped. dir 3 mm 100`, 손 떼도 안 움직임 |
| `move L 100` (안 막음) | 평소처럼 감, 메시지 없음 |
| `t5 3` | 1열 dx ±10 안 (T28 과 같음) |
