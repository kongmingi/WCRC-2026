# 강사님 hex 복원

`hex/` 의 두 파일(받은 원본)과, 그 프로그램의 아두이노 소스로 확인된 `Mission2B/` 입니다.

## Mission2B/ 가 hex 의 소스라는 근거
- hex 안 문장 = T1 (archive) 문장. "Check instruction blocks/camera" 는 T1 에만 있음
- 진행 순서 = T1 setup(): 462 전진 → FR 590 → 순서 자세 → 좌 304 → SL 476 → 순서 읽기 → 탐색 자세 → 858 → SL 558 → 우 110 → 1→4→1열 (FR 315, 열 간격 67 / 68 / 67, 돌아올 때 64 / 68 / 67)
- Zone A: 좌진 124 + 열 간격, 복귀 우진 124 / Zone B: 회전 → 후진 193 / 132 / 64 → 회전 → 366, 복귀 366 → 우회전 +1° → 124 → 우회전 +1.5° → 좌 67
- Finish: 1320 / 290 + 950
- 팔 관절 제한 (1024~3474, 211~2640, 722~3161), EEPROM 자세 읽기(40바이트, id 확인) 동일
- missionAssignments 표 { 1,A1 } { 1,B5 } { 3,A4 } { 4,B2 } { 4,A5 } { 5,A6 } 바이트까지 동일
- TODO-03~12 (B 정면·복귀 PSD 맞춤 등) 는 hex 에서도 비어 있음

## 추가로 hex 에서 확인한 값 (전부 T1 과 같음)
- PSD 맞춤: 비율 0.01, 시간 제한 3000, 반복 3 / 5, 안정 3회, 최소 속도 10, 허용 2(FR) / 3(SL), 대기 10, 속도 160
- PSD 측정 11번, 바퀴 반지름 30, 4095/2π, 가감속 100, 도착 대기 여유 1000 + 이동시간/4, 읽기 재시도 20 / 50, 바퀴 비율 0.98 / 0.99
- 순서 읽기: 3프레임 × 3번(배열 9칸), 같은 색 거리 10, 폭 45 × 160% = 7200, 2번 이상 같으면 확정, 대기 30
- 자세 번호 표: 탐색 {33,32,31}, 접근 {8,5,28}, 잡기 {9,6,29}, 빼기 {10,7,30}
- 팔 초기화: 홈 오프셋 0 / 238 / 799 / 0, 관절 제한 4개
- PerformMoveRotateAlign, PerformRightMoveAlign, PSD_ROTATE_CONTROL_RATIO(0.015) 는 T1 에서 한 번도 안 불려서 컴파일 때 빠짐 (hex 에 없음, 동작 영향 없음)

## hex 의 실제 프로그램 범위
- 시작 코드가 .data 를 0x835A 부터 166 바이트 복사 → 프로그램은 0x0000 ~ 0x8400 (33,792 바이트)
- 0x8400 ~ 0x10200 의 블루투스 설정·IMU·SW1 센서 점검 문장과 코드는 프로그램 안에서 한 번도 불리지 않음
- 부트로더 업로드는 쓴 페이지만 지우기 때문에, 예전에 올라가 있던 더 큰 펌웨어(블랙베리 기본 펌웨어로 보임)의 뒷부분이 남은 것
- 그래서 강사님 프로그램은 Mission2B/ 소스로 전부임
- 우리 빌드 크기(38KB)가 다른 건 Pixy2·Dynamixel2Arduino·NeoPixel 라이브러리 버전 차이

## 주의
- 팔 자세는 EEPROM 에서 읽음 (Tuning.h 아님). 우리 로봇 EEPROM 에는 이 형식 자세가 없어서 그대로 올리면 "Missing required Dropbox/carry pose" 로 멈춤
- `hex/TalkFile_BlackBerry_eeprom.hex` 는 **읽을 때 깨진 파일**. 메가 부트로더가 EEPROM 주소를 2배로 읽는 문제 때문에 16바이트마다 앞 8바이트만 들어 있음 (파일 8m+i = 실제 EEPROM 16m+i 로 맞추면 자세 1~36 번호가 정확히 맞음)
- 그래서 홀수 자세는 j1~j3, 짝수 자세는 j4 만 남아 있음. **이 파일을 로봇에 다시 쓰면 안 됨** (자세가 망가짐)
- 실제 로봇 EEPROM 은 멀쩡해서 프로그램이 바로 실행됨. 이 소스를 같은 로봇에 올려도 똑같이 실행됨 (업로드는 EEPROM 을 안 건드림)
- 팔 좌표가 0~4095 기준이라 우리 좌표(J1 앞 1013, 확장 모드)와 다름
